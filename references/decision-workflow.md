# 研究与决策方法

此文件是助手的执行方法。具体仓位、折价比例、收益目标和回撤阈值都不是已经确认的用户参数。

## 排雷：先决定是否值得继续研究

用最新定期报告、审计报告、交易所及公司公告检查风险警示/退市程序、财务真实性、资金占用、违规担保、债务违约和偿债能力、重大内控缺陷。区分确认事实、调查尚未结论、公司解释及缺失证据。

- **排除**：已确认达到个人红线，例如可识别的实质退市风险、严重财务诚信或治理缺陷。便宜不构成豁免。
- **暂缓核实**：重大风险信号尚未澄清、关键材料缺失；暂停新买入判断。ST状态、异常审计意见等需要核对成因和当前进展；不能写成“一定退市”。
- **可继续研究**：所核验材料未发现触及红线的事实。明确检索范围和日期，这不是安全认证。

质押、减持、问询、审计师变化等单一信号不能直接证明造假或利益输送；结合比例、用途、时间和回应判断。反过来，无风险警示标识也不能替代排查。现有持仓遇到红线，要说明可成交性、停牌和流动性约束，不承诺必能在目标价退出。

## 企业质量：用少量关键问题建立反证

首次深入研究或政策/行业发生实质变化时，使用[宏观政策—行业—公司传导框架](macro-industry-company.md)：只取与业务有关的宏观变量，分清政策文件、执行及回款阶段，检验行业需求、供给竞争和利润分配，再落到公司经营、现金与每股价值。可以从公司向外验证，不要求先准确预测宏观；不能用行业或国家支持替代公司质量与价格。指标按行业路由，已有研究只更新影响结论的变化。

先解释收入来自谁、客户为什么买、替代品和竞争者、增长驱动是否已经进入收入或现金流。通常看近3至5年并结合最新一期，周期行业尽可能跨一个完整周期；不为凑年数伪造数据。

- 利润：扣非及正常化盈利，剔除重大处置、补贴、减值反转等影响，避免把周期顶部当常态。
- 现金：累计而非只看单季现金转换，解释营运资本、应收回款、资本开支与分红覆盖。经营现金流减资本开支只是需注明口径的简化指标，不等同于任何模型下都适用的股东自由现金流。
- 回报：观察ROE/ROIC趋势及可比口径，拆开杠杆和经营效率，检验再投资回报。
- 负债：区分受限现金、到期有息债务和日常经营负债，做低谷压力分析。
- 金融企业不机械套用工业企业的经营现金流、负债率或自由现金流阈值；改用适合的资产质量、资本充足、拨备及流动性指标。成长制造业负自由现金流也不自动否决，需判断扩产收益和融资风险。
- 股息率注明历史/预期、税前口径及可持续性，不当成固定收益。央国企身份不能替代治理、效率和价格分析。

每家公司至少明确一个最可能证伪投资逻辑的经营事实。不能仅凭“AI受益”把电网、建筑、电池等不同生意视为相同成长确定性。

### 质量优先与商业模式检验

首次深入研究或新增投资时，按需补查[能力圈、企业质量与永久损失复核](business-quality-and-competence.md)。写明专业判断怎样转成可获得的经营与现金收益；护城河须有保持回报的证据，留存及扩张投入须有资本回报路径。不能把技术熟悉、国企身份或历史高ROE当作这些检查已经完成。

先判断企业是否值得长期拥有，再判断价格是否合适；不要因低PE、低PB或大跌而倒推它是优秀公司。以跨期事实评估需求耐久性、客户黏性或定价能力、竞争壁垒、正常化资本回报、现金创造及再投资空间，并列最薄弱的一项。成熟分红企业不必具备高增长，但分红须有持续经营支撑。证据不足标为待验证，不能仅凭龙头身份授予“伟大公司”标签。

做一次管理依赖检验：若明星负责人离任、由普通合格团队接任，客户关系、盈利和资本配置是否仍能延续？区分制度化经营与依靠个人关系、连续成功并购、精准择时或持续外部融资的增长。专业人才依赖本身不否定医疗或科技生意，重点检查人才梯队、流程和可复制性。管理层诚信、关联交易和股东利益仍单独排雷，商业模式优秀不能豁免治理风险。

候选比较时分开列“企业质量”和“价格吸引力”，再看与组合的匹配；不以一个总分让极低估值抵消质量不达标。可都不买，不为凑候选数量把平庸公司升级为买入建议。

## 估值与舒服买入区

只在模型可解释、资料足够时计算；不强制普通散户使用复杂DCF。

建立或更新估值时，按[估值证据与变更记录](valuation-evidence.md)保留关键输入、缺口影响及前后变化。以“披露的分业务经营与财务数据 → 正常化调整 → 增量经营假设 → 每股盈利或现金流 → 价值区间”解释推导，不要求为不适用的环节强造数值。

- 扣非净利润可作起点，不自动等于正常化盈利；检查异常利润率、阶段性费用、减值和折旧。扩产情景同时考虑爬坡时间、折旧、维护投入、营运资金和融资，不能只增加收入。
- 未披露的利用率保留为假设；分部收入、利润率、固定资产变化可交叉检验，但不能冒充直接测得的利用率。维护性资本开支无法合理拆分时，做区间敏感性或将现金流法降为辅助，不强报精确自由现金流。

先区分成熟、规模化成长、早期商业化、经营反转与周期阶段。成长企业、用户偏进攻或过度等待时，使用[成长企业估值与进攻、防守校准](growth-and-calibration.md)：未来收入、利润率、再投资、融资摊薄与商业化时间共同进入估值，反推现价要求；不能将低当期利润直接等同于低价值，亦不能只按远期市场空间估值。双向校准影响研究侧重点，不机械反对用户。

按[成长参考第7至9节](growth-and-calibration.md)检验PE/PB与ROE、资产质量和资本成本，独立评价增长速度、经营可预见性与价格预期。高成长50%主观损失容忍须先明确范围再转成金额预算，不把稳定需求等同于高利润增长，不把亏损公司自动改用PB。

1. 选择适合行业的主方法：正常化盈利与合理估值倍数、资产价值及盈利能力、可持续分红，或适用时的现金流折现。尽可能用第二种适用方法检验，不能简单平均互相冲突的结果。
2. 展示保守/基准/乐观假设、对应价值区间、主要不确定性及反证；未知概率不编造加权期望。
3. 给出价格区间时说明安全边际的基准，例如 `买入上限 = 审慎估计的每股价值 × (1 − 安全边际比例)`。用户于2026-10-08确认：审慎估值不等于最悲观的压力情景。分别说明正常盈利、估值倍数、额外折价各自补偿什么风险，避免对同一风险无解释地重复扣减。折价比例须有理由且标为本次建议；不能把情景表机械变为必须等到最低档才买的规则。可用包含分红、增长和期末估值的预期回报情景交叉检验，注明回报目标是研究假设；若已在折现率中计入风险，不再无解释地重复打折。
4. 可以表达“价值观察区 / 条件性买入区 / 深度折价复核区”。按v1.7，质量证据充分的优秀企业可以在合理价格进入条件性买入区，不强制先达到深度折价。说明拟持有期、正常化每股盈利/现金流、增长、分红、期末估值与对应回报，检查增长降低或估值收缩时的结果；具体回报目标是本次假设，不是用户固定门槛。不以未来估值持续扩张作为唯一回报来源。合理估值仍须通过其他买入条件；跌入深度折价区更需检查基本面变化，不自动加倍买。
5. 标注估值日期、数据期、关键假设、价格币种、分红除权/股本变化及失效事件。新财报、重大治理或经营变化时更新，不能无限沿用旧价格地图。

示例仅用于解释计算：假设保守每股价值10元，建议折价20%，则买入上限8元；如果保守价值下调至7元，同样折价下的新上限为5.6元，原8元即失效。该示例不是任何股票的目标价，也不是用户已确认的20%固定折价。

禁止把“数据不够”改写成小数点后两位的精准买点。资料不足时提供条件模型或明确等待。

### 估值卡的必填内容

每个准备进入买入讨论的候选，列出：证券代码/市场、估值日期、财报期及公告链接、主估值方法、关键输入及正常化调整、保守/基准/乐观情景、价值区间、安全边际依据、买入上限、反证与失效事件。复杂度控制在能用一页解释；适用时才展开详细模型。

- 例如正常化盈利法须展示正常化归母利润如何得出、股本与每股收益口径、合理PE的经营依据；说明一次性项目、周期、潜在摊薄和会计口径。不能直接将历史最低倍数当合理倍数。
- 区间应由经营和估值假设推导，不是把现价上下浮动任意百分比。现金流折现须匹配现金流/折现率口径、债务及股权价值，避免股权法重复扣债。
- 针对最重要的盈利与估值输入至少做一次敏感性检查。交叉方法出现显著矛盾时解释差异；无法解释则暂缓，不平均成看似可靠的目标价。
- 明确三种证据状态：“足以进入条件性买入讨论 / 只能列观察 / 无法可靠估值”。关键财务真实性未澄清或业务理解不足时，不得用更大折价抵消。
- 升高买入上限必须记录新增经营证据，或可复核的方法纠错，以及前后假设、风险处理和估值差异。方法纠错须明确是纠正计算、口径或重复折扣，不伪称公司盈利改善。仅有股价上涨、热点升温或新增资金，不构成上调理由。
- 上调、下调或撤销估值均展示“原依据与区间 → 新证据或纠错 → 输入变化 → 新区间与结论”。多项输入同时变化时说明交互影响，不把单项敏感性直接相加；不能量化归因时保留方向及范围，不伪造精确贡献。
- 盈利稳定且证据充分的企业可按审慎估值讨论正常建仓；成长或恢复待验证的企业可在理解兑现、融资和失败风险后，以有依据的前瞻估值及首笔预算讨论参与，不要求全部未来利润先兑现。后续加仓须复核经营证据，不能只因跌到下一档执行。重大治理或财务问题尚未澄清时暂停新增。首笔小不等于买价可无视估值，等待机会成本也不等于必须持股。
- 新定期报告、重大经营或治理变化、分红除权和股本变动触发重算。在相关复核完成前，旧价位暂停用于新增买入判断；不意味着持仓自动卖出。

执行顺序：先定估值上限与总预算，再提限价和分批方案；同时执行[流动性与监控要求](execution-monitoring.md)。后续每批须重新满足四道条件；不能把固定跌幅当作自动加仓触发器。用户已要求直接给方案，可采用明确标注的建议风险参数完成条件配置，不把参数尚未逐项确认扩大成拒绝给出可审核方案。

## 仓位、现金与执行建议

按[能力圈与组合角色](business-quality-and-competence.md#11-汽车检测能力圈与组合角色2026-10-22确认)区分研究优先级、核心仓、其他价值配置、进攻探索和现金；角色不是买入许可或固定比例。汽车检测为专业起点，拟交易仍须合并检查共同汽车客户、研发预算、账期与政策冲击；不得为形成汽车主仓或进攻仓扩大当前交易授权。

配置范围须匹配持续研究能力和低频副业精力，不为凑数量加入看不懂的个股。缺少持续研究能力时可以比较宽基指数路径，但不能把主题基金当充分分散、不自行设指数/个股比例或替用户换仓。重要等待决策写价格与信息两类条件；复盘回到当时证据，不凭事后上涨认定不买是错误。

给具体配置前，需要用户当前可投资资产、持仓市值和现金、期限、资金用途及可承受损失；缺少时可给标明假设的示例，不能说“适合你配置多少”。用户已选择总资金动态待定，不反复要求固定终身总预算，仅在具体配置确实需要时确认本次可用金额。

- 统一分母为本次投资组合净资产，说明是否包含预留投资现金；生活应急资金另列。按当前市值衡量仓位，区分初始买入限制和涨跌后的复核线。
- 未来可能追加的资金不提前计入分母；追加资金到账后再更新可用现金和敞口。“行情好”不是自动追价、买满或提高估值的依据。
- 组合层面同时看单股集中度、行业、产业链、共同客户及宏观驱动。具体上限需用户确认，不能复制旧25%/30%/40%/45%数字。
- 回撤承受能力要与组合的可能损失匹配。例如假设某股占比25%，其下跌40%、其他资产不动，单股对组合损失约10%；这是简化压力情景，不是损失上限，也未包括相关资产同步下跌。
- 如果用户可承受损失很小，就应重新讨论权益总敞口，而不是承诺选“安全股票”可保证不超过该损失。
- 无足够安全边际时允许不交易；没有买到不自动提高限价。加仓需要价值判断仍成立、风险未触发且不超总预算。
- 提供股数或限价建议时重新核验具体市场/板块的申报数量、价格单位、涨跌幅、交易时段、可用资金、费用及卖出约束。不统一假设所有A股最小买入单位都相同。
- 限价不保证成交，预设退出价也不保证可执行；停牌、连续跌停和跳空均需纳入风险说明。
- 只输出供用户审阅的方案，不操作券商交易。若用户另提持续提醒需求，使用可用的真实自动化能力，并说明数据源、运行频率和提醒条件。

### 动态风险预算表

不要求固定终身本金。具体配置时建立同一时点的快照：持仓市值、投资现金、已到账新增资金、计划提取/预留资金，注明币种与日期。已在现金余额中的新增资金不能再加一次；预留近期用款不作为可买入现金。

用变量保留个人参数：单股上限 `u_i`、共同风险组上限 `u_g`、最低投资现金比例 `c`、组合情景损失预算 `R`。这些值须结合期限及实际承受能力提出并由用户确认；缺少时输出未定项和条件区间，不擅自设25%等数值，也不反复追问总本金。

同一笔拟买入的计算口径：

- `A = 当前持仓市值合计 + 当前投资现金`，新增资金只在实际到账且尚未包含在现金时加一次，提取资金先扣除；`A≤0`时不计算仓位。
- 为本次交易保守预留费用 `F`，用 `A'=A−F` 和 `C'=可用投资现金−F` 计算拟交易约束；买入金额 `x` 指不含费用的市值。A'或C'不合理时停止金额建议。
- 单股容量：`u_i×A'−当前该股市值`。每个相关风险组容量：`u_g×A'−该组当前市值合计`。现金容量：`C'−c×A'`。
- 每个压力情景对每只持仓只指定一个损失比例 `s_i`，情景损失金额 `L=Σ(市值_i×s_i)`，比例 `L/A'`。这是假设冲击的结果，不是概率预测、历史回撤或最坏损失保证。
- 对拟买入股票在该情景下的损失比例 `s_new>0`，风险预算容量为 `(R×A'−L)/s_new`；联合情景均须检查。不能设虚假低冲击来放大预算。
- 拟买入上限为各单股、风险组、现金及适用情景容量的最小值，再限制为不小于0；已有超限时明确指出，不能只报0而隐去存量风险。若已有超限风险需先处理，不凭未来追加资金豁免。
- 最后按目标价格、适用交易单位及费用重新计算拟交易后的实际仓位。公式只是预算上限，排雷或估值没通过时允许买入金额仍为0。新增资金较多时，还要检查绝对损失金额是否超出承受能力，不能只看比例下降。

每只证券标注行业及共同经营驱动，例如共同客户、电力投资周期、房地产信用风险。风险组可以交叠：每组分别限制；同一联合情景中每只证券只计一次损失，禁止把重叠风险组损失直接相加造成重复计算。

至少检查与组合有关的单股受损、共同驱动受损和广泛下跌情景，解释冲击幅度的依据；资料缺少时只能列假设演示。若需要设置回撤复核线，须调整入金出金影响，不能用追加资金制造净值修复。

实际减仓或新增交易造成多个变量变化时，按完整交易后快照重算，不把单笔公式机械外推为整个组合优化。数字是约束工具，不替代用户对损失金额的理解。

## 持有、卖出与复盘

把“价格波动”与“投资逻辑改变”分开。既不能因跌20%机械否定公司，也不能以价值投资为由忽略风险上限。

采用适合副业投资的节奏：季报查变化、半年报和年报深入复核，重大事件及时处理；具体日程沿用用户已确认的计划。以每股盈利、现金创造、资本回报和竞争优势的兑现检验长期逻辑，不以日涨跌催促行动。减少重复小额交易，保留资金弹性；不设必须每日决策、每月买入或限期满仓的要求。

“不交易”须区分价格不合适、质量不合格、关键证据未清、预算不足和持仓逻辑未变。首次决策或实质变化时写清理由、重新考虑的可观察条件及下次复核日期或事件；质量不合格不能只设置降价触发条件。例行监控无变化时遵守安静与去重规则，不每日重复解释，不因收到报价就生成买卖建议。等待需复核，不能让估值过期；严重风险不能以耐心为由搁置。

优先检查：治理/退市红线，原逻辑是否被证伪，质量是否实质下降，估值是否严重透支，用户资金用途与组合限额是否变化。更优机会换仓应覆盖税费、冲击、估值误差和新标的不确定性；不能把频繁追涨包装成优化。

### 买入前预写、事件发生后执行

每个候选保留最关键的2至3条可检验投资理由，逐条绑定：观察指标、原始依据、使判断失效的事实或区间、观察期限、触发后动作。行业壁垒等难以量化的理由可使用可核验事件，不能用“长期仍看好”作不可证伪的结论。

| 复核状态 | 典型条件 | 助手应提出的动作 |
|---|---|---|
| 继续持有/观察 | 核心逻辑仍成立，估值与风险预算有效 | 说明依据和下次复核点；是否加仓另过买入检查 |
| 暂停加仓并核实 | 盈利或现金异常待解释、重要资料缺失、模型过期、一般集中度超限 | 列缺失证据、负责查询的动作及具体日期或事件期限；不得无限期以观察为由搁置 |
| 评估减仓或退出 | 红线确认、核心逻辑被证伪、风险承受能力发生实质变化，或估值/集中风险需要调整 | 给出减仓或退出的理由与优先级、可成交限制及尚存不确定性；不等回本、不等例行财报 |

重大但尚未证实的风险先暂停新增敞口并立即复核；若潜在损失已不可承受，可以在事实最终定论前评估降风险，不能以等待调查为由要求死扛。不同原因分别处理：一般估值偏高不等于财务诚信红线；集中度因上涨超限可考虑停止加仓、合理再平衡或减仓，不能一律清仓，也不能一律不动。

若核实期限届满仍缺关键证据，继续禁止新增，并明确评估现有敞口是否应降低；不可反复延长期限而不说明理由。入场时没有写条件的旧持仓，从当前可得事实补建基线，标明后补，不假装是事前计划。

交易前后记录：原判断、当时可得证据、当前变化、决定、组合影响和下次复核点。新证据允许更新观点；调整失效条件必须说明原因，不能仅因条件将触发而临时放宽。涉及行情或公告复核只在实际调用时完成，不宣称后台自动发现事件。

用户要求复盘时，记录实际决策依据、当时已知信息、失效条件和事后结果。区分过程正确但亏损、过程错误但盈利；没有交易记录不得评用户执行能力。对策略作长期评价要核对投入取出、分红、税费、回撤及匹配期限的基准；不用一次交易证明有效。

## 输出示例结构（按需缩减）

1. 当前结论：排除、暂缓、观察、条件性候选、持有复核或评估退出。
2. 关键证据及日期：退市/治理、业务、利润/现金、负债、资本回报。
   首次深研或有实质变化时补充宏观政策与行业传导，说明它改变哪些经营或估值输入；技术指标不作为内在价值依据。
3. 最强反证与未知：什么事实出现会推翻判断。
4. 价格判断：估值方法、假设、区间及失效条件；无依据则不报价。
5. 组合影响与行动条件：已确认约束、缺失参数、下一次复核点。

不要用综合评分掩盖红线，或把“值得研究”升级成“马上买入”。
