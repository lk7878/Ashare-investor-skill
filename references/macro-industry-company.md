# 宏观政策、行业与公司：长期价值研究的传导框架

2026-10-18，v2.3。用于首次深入研究、重大政策/行业变化、财报重估及跨公司比较；例行持仓回复只更新影响决定的变化。方法由助手按用户要求整理，不是视频逐字稿，也不是已经验证的收益模型。与[企业质量](business-quality-and-competence.md)、[成长估值](growth-and-calibration.md)、[研究质量](research-quality.md)配合；排雷、估值和资金约束继续有效。

阅读导航：第1节研究顺序；第2节宏观政策；第3节行业；第4节公司指标；第5节行业适配；第6节A股/美股；第7节技术分析与输出；第8节资料边界。

## 1. 三层解释最终落到每股价值

把问题连起来：**宏观/政策改变什么 → 行业量价、竞争与利润池如何变化 → 公司实际能获得多少 → 扣除投入、债务、少数股东权益和融资摊薄后，普通股股东得到什么 → 现价是否划算。**

排雷后，可从熟悉公司向外验证，也可从行业机会向内筛选；不强制先预测宏观或判断大盘见底。宏观和行业用于界定经营条件、识别共同风险，不能因“行业好”跳过公司质量，也不因短期经济偏弱一律否决有韧性的企业。

首次研究挑选最影响价值的少量变量，通常每层1—3个即可；需要时扩展，不为凑指标制造数据。每个关键变量记录：来源及可用日期、期间/单位、当前值与跨期趋势、适用同行或正常周期参照、正反传导路径、未知、影响哪项估值输入、下次验证点。阈值由商业模式和历史背景解释，不设统一分数或固定“基本面/技术面”权重。

## 2. 宏观与政策：检查传导，不预测所有经济数据

### 按业务选择相关变量

| 变量组 | 可选指标 | 如何进入公司分析；常见误用 |
|---|---|---|
| 需求与经济周期 | 实际/名义增长、PMI新订单、消费、制造业/基建/房地产投资及相关实物量 | 映射客户需求、销量与付款能力；GDP增长不代表公司收入或每股利润同幅增长，PMI扩张不等于股价必涨 |
| 价格与成本 | CPI/PPI及公司实际产品价、原材料、能源和人工成本 | 检查售价与成本差、传导时滞、库存成本；宏观价格指数不能代替具体产品价差 |
| 信用与资金成本 | 利率和期限结构、社融/信贷结构及实体融资需求、必要时M2 | 区分借款成本、客户资本开支、信用风险和估值折现；M2增加不等于资金同比例流入股市，降息不必然提高所有金融企业利润 |
| 财政与产业政策 | 正式预算、执行进度、政府采购/电网投资、补贴税收和行业准入 | 分清行业支持、资金到位与企业收入；政策也可能引来过度扩产、价格竞争、回款延迟或公共服务义务 |
| 外部条件 | 公司相关汇率、出口地区需求、关税/准入/贸易管制 | 按收入、成本、债务与套保敞口判断方向；汇率变化不能简单对所有出口企业作同一判断 |

数据优先来自统计、央行、财政及行业主管部门原文，再与客户/公司披露交叉核验。说明季节性、基数、修订和领先/滞后关系；没有可靠一致预期，不用“超预期”措辞。对非关键宏观变量可以说明影响有限，不强行填表。

### 政策证据分阶段

每项足以改变结论的政策，保留：**发文机关、文号/原文链接、发布日期与生效日、适用地区/对象、目前阶段、资金和执行条件、公司暴露、受益及受损路径。**

| 已观察阶段 | 能支持什么 | 尚不能推出什么 |
|---|---|---|
| 讲话、倡议、征求意见稿 | 提出方向与待验证情景 | 已正式执行、公司确定受益 |
| 正式文件、细则与预算 | 核实约束、资格和实施条件 | 资金已到公司、收入或利润已实现 |
| 招标、中标/有效订单 | 研究可获得业务与履约安排 | 框架额度全部执行，合同额等于收入或利润 |
| 交付、验收及收入确认 | 检查订单转化、毛利与归属 | 已收到现金或具有同等利润质量 |
| 回款与可持续现金回报 | 验证价值传导兑现 | 未来永远重复、所有新增资本都同样高回报 |

这些是常见证据阶段，非所有政策都必须经过招标；减税、准入和价格监管按实际机制验证。尚未兑现的成长可进入有依据的情景，不要求先收到全部未来现金才研究参与；但阶段不能写错，现有利润与远期期权分开。

同查“谁出钱、谁定价、谁拿利润、谁承担扩产和回款风险”。至少检验一个政策落地延迟/弱于预期/退出的适用情景；不把政策利好在收入、利润率、PE溢价和折现率中无解释地重复计入。若只影响短期情绪而没有经营证据，注明不调整长期价值；真正改变估值核心输入时才按现行重估规则暂停和更新旧价位，不因普通政策新闻频繁交易。

## 3. 行业：需求空间与股东利润分开

优先说明以下最相关的问题，不要求每次全部展开：

- **阶段和周期**：导入、放量、成熟、衰退与周期位置分别判断；长周期成长也可能经历库存、价格和产能低谷。需求、库存/利用率、价格与利润等证据不足时不宣布拐点。
- **可达市场**：区分总需求、公司能服务的市场及可获得份额；核对付费客户、替代技术、渗透率和商业化时间。AI耗电、老龄化或固态电池空间不能直接当上市公司收入。
- **供需与盈利分配**：销量/装机或出货、有效产能和利用率、库存、售价与成本差、竞争者扩产、集中度及上下游议价权。行业增长可与单位利润下降并存，龙头份额增长也可能依靠降价换取。
- **壁垒与回报**：成本/认证/切换成本如何转成定价、留客和资本回报；研发、良率、客户认证、送样、量产、实际销售是不同阶段。储量不是产量、规划不是可用产能，订单也不是无条件利润。
- **竞争与政策反作用**：准入、集采/收费、电价、补贴退出、海外限制、重复投资和新技术替代，具体判断谁受益、谁承压。

同行比较匹配产品、客户地区、收入确认、业务结构和周期位置。财务口径不一致先调节或说明，不能用跨行业毛利率、ROE或PE排名决定买入。缺数据时给方向和核验条件，不虚构行业平均值。

## 4. 公司：在“盈利、财务、价格、竞争力”上补足现金和每股回报

“盈利能力、财务状况、价格估值、核心竞争力”可作快速入口，不能缩成四个孤立比率。深研仍须联读利润表、资产负债表、现金流量表与附注。通常近3—5年加最新一期，周期企业尽量覆盖完整周期；新企业历史不足注明范围，不自动否决成长。

| 模块 | 按业务选取的指标/事实 | 必须解释的问题 |
|---|---|---|
| 主业增长 | 分部收入、量/价/结构、订单转化、同店或老客户、海内外构成 | 内生还是并购/汇率；订单何时确认；集团收入增长能否归属上市公司普通股股东 |
| 盈利能力 | 毛利率、经营利润率、正常化归母利润、适用扣非口径 | 提价/效率还是补贴、投资/公允价值收益、税率/减值变化；拆单季和累计，扣非不必然等于主营经常利润 |
| 现金质量 | 跨期经营现金流、应收/合同资产及账龄、存货、资本开支、回款 | 客户是否真正付款；供应商账期、预收和保理等对现金的影响；维护/扩张投入分开，缺披露用范围，不伪造自由现金流 |
| 资本效率 | 平均权益口径ROE、适用ROIC、资产周转及新增项目回报 | ROE改善来自利润率、周转还是杠杆；采用相容口径检验再投资回报与资本成本，不用历史高ROE保证未来 |
| 生存与财务风险 | 可用/受限现金、债务到期结构、利息保障、担保/承诺、减值；必要时流动/速动比率 | 资产能否变现、短债能否覆盖、低谷能否融资；流动比率高不保证应收和存货质量，账面现金多不等于可全部分配 |
| 护城河与治理 | 客户留存、定价/成本、替代与认证、管理制度、关联交易及资本配置 | “优势”怎样持续保住回报；诚信单独排雷，不因商业模式好或名气大放行 |
| 每股回报与价格 | 正常化/前瞻EPS与现金、适用PE/PB等、普通分红持续性、潜在摊薄及回购注销 | 总利润与每股增长分开；净现金/投资资产和相关收益避免重复估值；回到审慎舒服区、成长参与区及现价隐含要求 |

可用杜邦分解 `ROE≈同口径净利率×资产周转率×权益乘数` 辅助解释；采用一致的利润、平均资产/权益及归属口径，差异说明。普通流动比率=`流动资产/流动负债`，不将大于某数值设为跨行业买入条件。PE/PEG、PB、DCF等的适配与增长风险继续按[成长参考第7—9节](growth-and-calibration.md)处理，不新增统一门槛。

每个重要指标比较“跨期趋势—适用同行/正常水平—变化原因—未来可持续性”，并注明口径与来源；指标恶化先分解，不能一律当短期波动，也不因一个单季噪声自动推翻长期价值。

## 5. 行业指标路由：只取适用项

| 类型 | 优先补查 | 防止误判 |
|---|---|---|
| 汽车/电池/材料 | 销量与单价、单位利润、产品/地区结构、有效产能及利用率、良率、客户验证、质保/召回、回款和扩产现金 | 把新能源/固态主题当利润，把自供与对外销售重复计算，把原材料资源等同电池级材料产能 |
| 检测及技术服务 | 政策标准与客户研发预算、订单/合同、平台投产利用率、收费、折旧维护升级、验收回款 | 平台建成后零再投资；汽车销量与检测收入机械同比例增长 |
| 电网设备/工程 | 客户实际预算与招标、在手订单质量、交付验收、分部毛利、合同资产/应收回款、履约和担保 | AI用电需求直接乘成订单利润；中标金额直接当当期利润或现金 |
| 水电/核电等公用事业 | 有效装机、发电量/利用小时、来水/检修、实际电价、燃料、债务与利息、维护和建设投入、可分配现金 | 稳定需求等于高利润增长；电量增长不受电价、资源/容量与资本开支限制 |
| 医疗服务/器械及医药流通 | 收费/医保/集采、患者或终端需求、同店增长、付款方、销售费用、应收存货、合规及扩张回报 | 老龄化需求直接变利润；流通高收入低毛利与器械/医院跨业硬比 |
| 银行 | 净息差、资产质量迁徙、不良/关注及逾期、拨备/信用成本、普通股资本、ROE与分红能力 | 低PB自动便宜；降息只利好而不影响息差，不使用工业负债率/CFO门槛 |
| 保险 | 寿险新业务价值及假设、合同服务边际及释放、营运利润及定义、财险综合成本率、投资收益、资产负债匹配、偿付能力与分红汇出 | 股市上涨只影响收益不影响波动/资本；集团投资利润等于稳定经营增长；AI使用量直接等于净利润增量 |
| 半导体/AI与早期商业化 | 可付费客户、竞争替代、订单交付、有效产能/良率、毛利、研发费用化/资本化、现金消耗与融资摊薄 | 研发或专利数量等于壁垒；TAM直接计入收入；没有盈利就自动用PB或禁止前瞻估值 |

## 6. A股与美股：按制度、行业暴露和期限适配

保留“在A股主动检查宏观与政策传导”的研究重点，但**不把“A股只看政策、美股只看业绩”或“A股政策影响始终更大”写成规则**。跨市场强弱比较需要明确样本、行业、事件、窗口及预期变化；仅凭视频、单次行情或指数涨跌不能证明。

| 比较维度 | 本Skill的处理 |
|---|---|
| 政策和需求暴露 | 对涉及准入、政府/国企采购、收费定价、信用及产业扶持的公司，细查官方规则与执行。美股也评估利率、财政税收、监管和贸易约束；两边都按实际业务及地区暴露研究 |
| 短期价格与长期经营 | 流动性、风险偏好和预期差可以驱动短期估值；长期仍检查盈利、必要投入、分配与每股价值，不能由“政策市”推出价值分析无效或必须跟热点 |
| 样本可比性 | 指数行业权重、国际收入、盈利阶段、股东回报方式和会计口径会影响观察结果；不把指数构成差异都归因制度，不直接搬用美股估值倍数、折现率和分红频率 |
| 所有制与治理 | 核实控股股东目标、少数股东利益、资本配置、关联交易和公共任务；不把国企身份等同保本，也不把所有国企判为低效 |
| 交易与投资者约束 | 具体执行再核验上市地点/板块、资格、涨跌幅、交易/结算、申报单位、停牌/退市、税费及币种。不要混淆美股T+1结算与禁止当日卖出，不在方法表写死跨板块交易规则 |

政策判断必须写入受影响业务、经营情景及价值，而不只是附在“宏观环境”段落。最值得寻找的是：在合理政策情景下能保持回报，即使支持力度不及预期也有生存与现金韧性的公司；不是国家支持就可任意高价买入。

## 7. 技术分析的边界与低频输出

技术面用于流动性、买卖价差与深度、异常波动、供给/解禁、事件风险及委托安排；先分清复权K线、除息/股本变化和实际可成交价格。价格趋势、成交量、筹码估算、MACD/RSI等可以提示研究问题，不能证明内在价值、主力意图或必然反弹；不因为“超卖”“跌破90%筹码下沿”授予买入许可。

基本面和估值有效且其他条件通过时，不额外要求所有均线或技术信号同时转好才允许讨论建仓；重大未解释的异常风险仍可暂停新增。不用短线技术止损自动替代长期逻辑退出，停牌、跳空及流动性约束仍纳入风险。

首次研究或实质变化，输出最影响决定的内容：

1. **宏观/政策**：关键变量、事实阶段、传导与不利情景。
2. **行业**：需求、供给竞争、利润分配及公司相对位置。
3. **公司**：经营兑现、财务/现金、资本回报与最强反证。
4. **价格与行动**：前述变化影响哪些估值输入，审慎舒服区/成长参与区、失效事件；具体数量仍核实资金和现行计划。

以上是解释结构，不是四项打勾即可买入。已有基线只报变化；不把宏观框架变成每日政策播报或自动扩大候选。方法更新不改变持仓、预算、现行价格/批次、有效期和已授权监控范围；用户要求另行重估标的后，才按原流程研究与版本化处理。
