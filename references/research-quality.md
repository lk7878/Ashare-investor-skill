# 研究质量与A股适配

适用：具体财务数字、历史复盘、财报更新、分红及组合相关性分析。只加载当前需要的部分，不把每次问答变成长报告。以下是对已审阅公开方法的独立设计与A股适配，不安装或执行被参考仓库。

## 1. 证据时点与口径

决策关键数字保留：字段、数值、单位/币种、财务期间、合并或母公司口径、原文位置和链接、公开披露时点、可用于本次研究的时点、抓取时点。用事实、计算、估计、假设、判断、未知区分证据性质。

- 财报截止日不等于发布日。历史复盘只用当时已公开可得的信息，不将之后发布的财报、更正或后来训练得到的结论放回过去。盘后公告可以用于盘后的研究，但不能假定公告发布前已经据此成交；实际可交易时点另核验交易日历。
- 原披露和更正版分开保存引用。获取旧文件的日期可以晚于历史分析日期，关键是该版本何时已公开可得，不能因为今天下载就断言过去不可得。
- 同一公告被多家媒体转载仍是同一原始证据。独立计算可复核算术，但不是对公司财务真实性的独立证明。
- 对收入、归母净利润、EPS、股本、市值、现金、债务等关键输入，先统一元/万元/亿元、币种、期末/平均、年度/单季/累计/TTM、扣非/未扣非口径，再比较。不能把冲突数字取平均。
- 市值计算匹配实际股份类别、各自价格和币种。A+H公司不能无说明地用A股价格乘全部股份当作实际两地合计市值。EPS所用加权平均股本与某日市值所用时点股本也不可混淆。
- 关键数字核对结果写成已找到原文、已复算、口径冲突、时点不适用或无法核实。没有查到不等于为假；程序算对不等于输入为真。

只有重大事实真实性或估值核心输入存在无法解决的缺口时暂停相关结论。缺少同行排名、市场一致预期等不必妨碍已有证据支持的基本面研究；精确说明哪种结论暂时不能给。

## 2. 财报与公告更新：只分析变化

已有研究基线时，使用“上次判断/数值—本次原文事实—变化原因—对估值和行动的影响”四列。优先看主营业务、正常化利润、现金回款、负债和资本配置。新候选没有基线时先建立基线，不虚构旧预期。

- 比较一致口径，分开业绩预告、业绩快报和正式报告；这些是不同证据阶段，不是可互换数值。季报累计值不能直接当单季度，推导单季度时说明所减期间及版本一致性。
- 只有获得有时间戳和来源的市场一致预期才说“超/低于市场预期”；否则比较公司公开承诺或我们之前留存的估计，并准确命名。
- 重大合同核对是否为框架协议、履行条件、收入确认及回款节奏；合同额不能直接当利润。回购计划、实际回购、注销及股本变化分开看；定增等事件检查原股东每股权益影响。
- 为重要公开承诺建立简短记录：发布日期、具体承诺、目标期、实际兑现、证据。业绩承诺不等于保证，未兑现也需查原因，不能据此直接认定造假。
- 更新每条投资理由为加强、削弱、证伪、无变化或证据不足；记录对应证据与下一次观察点。状态加强不自动触发加仓，仍回到估值及预算检查。

## 3. 反方检验与价格隐含预期

形成条件性买入结论前，写出最有力的不买理由，并说明什么新证据会推翻这一反方理由。证据少时可只有一条，不为凑数创造风险。区分正常周期压力与永久性竞争力损伤，不能为唱空而猜测违法。

在模型适用时反问：当前价格要求怎样的正常化盈利、利润率或增长？这些要求是否与产能、行业规模、竞争和资本需求相容？最简单的反推可用 `隐含每股盈利=现价/有依据的合理PE`。它是条件推导，不是市场真实一致预期；复杂DCF不适用时不硬做反向DCF。

不沿用做空策略、主观概率或技术止损参数；不把反方演练当作最终看空结论。参考材料中的95分、胜率和评级不能提升自己的评分。

## 4. 股息率、分红质量与实际回报

2026-10-09新增：个股买入机会、持仓复核和多股比较都纳入这一维度，简答可压缩为一列；不为凑数编造预测。不设跨行业统一最低股息率或评分权重，质量优先、合理价格的原则不变。

### 口径与展示

- **历史年度股息率**＝最新完整利润年度对应的已实施税前每股现金分红合计÷研究时点未复权股价。标明利润年度及价格时间；例如同一年度的中期、末期只各计一次。若尚有未实施部分，分开列示，不把部分实施金额冒充全年金额。
- **TTM股息率**＝截至研究日最近12个月已实施现金分红合计÷同一时点股价，窗口统一按除息日归集，并核验实施公告及支付安排。它可能混合不同利润年度，须与历史年度口径分开；不是新买入者可追溯领取的收益。
- **预期股息率**＝未来明确期间预计可获得的税前每股现金分红÷拟买入价。区分公司预案、已批准方案及分析假设，注明预测期、来源、领取条件和不确定性。刚过去的除息不能再算作新买入者未来现金收入；无法可靠预测则只给历史值。
- 每笔标注普通/特别分红、预案/批准/实施/派发阶段；普通分红与含特别分红的总额分开。派息率＝同期间归属普通股股东的现金分红÷对应普通股可分配口径利润，说明使用的利润口径及一次性项目。每10股派X元先除以10，不将一次中期分红机械乘2或乘4。
- 对送转、拆并股、增发及A/H股份差异统一每股口径、币种和股本基础后再比较。历史成本股息率只作个人记录；新增买入和持有机会成本比较使用当前价格，不能因成本低而忽略当前估值。
- 多股比较默认给一项可比历史口径、分红持续性判断和行动影响；缺数据写“待核实”，经核验确无分红才写0。税后金额按实际投资者类型、持有期及现行规定另核验，不默认人人相同税率。

### 持续性与高股息误判

看近3—5年普通每股分红、削减/中断记录及派息率，并用正常年份与低谷情景检查；历史不足则注明实际覆盖年数。核实分红是否依赖资产出售、一次性利润、消耗现金或借款，以及分红后债务偿付和必要再投资是否仍有保障。不能把股价因基本面恶化而下跌造成的股息率上升当作自动买点。

工业企业结合累计经营现金流、必要资本开支和现金储备，不以单季现金流或粗略“经营现金流减全部资本开支”直接判定分红安全。银行侧重普通股资本、资产质量、拨备和监管分红约束；保险侧重可分配利润、资本汇出能力、偿付能力及资产负债匹配。盈利或适用现金流为零/负时，常规覆盖倍数可能无意义，不能由负比例得出安全结论。

| 企业类型 | 股息率在判断中的作用 |
|---|---|
| 银行、保险、成熟公用事业 | 作为重要回报来源；优先验证普通分红持续性、资本或现金约束，再与增长和现价比较 |
| 成熟制造、医疗服务、技术服务 | 平衡分红与扩张回报；持续低分红时检查留存收益是否真正提高每股盈利与现金创造能力 |
| 成长科技、电池等高投入企业 | 不因低股息直接排除，也不无条件接受不分红；核验再投资回报、资本需求、融资和摊薄 |
| 资源、工程及其他周期企业 | 用跨周期盈利和普通分红判断，防止景气高点派息或一次性特别分红造成高股息假象 |

### 对估值、行动与监控的影响

分红收益、每股盈利增长和期末估值共同构成回报分析。派息率与增长假设须能同时成立；以借债或稀释股东维持高分红不自动创造价值。使用未来分红加期末股价模型时，按真实可领取时序计算，期末价格注明除息口径；已在模型中计入分红，不再额外加一次股息率。复盘采用含分红总回报序列时也不重复加派息。

可用“可持续普通每股分红÷有依据的要求股息率”作交叉估值，要求股息率是当次假设，不能成为统一硬门槛，不能凭此单独授予买入许可。高股息不抵消质量、治理、流动性和组合风险；回购计划不等于现金分红或已注销，须另查每股权益变化。除息不是额外无风险收益，不为抢分红增加交易次数。

公告出现减派/停派、特别分红、分配方案变更或除权除息时，复核原股息率和依赖它的估值、价格口径；持续性改变才更新投资理由，不把每次例行分红都视为利好或交易信号。现有监控仍按已授权范围、现行计划及去重规则执行；本节不自动添加股息率触发器、改价或开启新任务。

## 5. 相关性与数据能力

有可靠历史行情且用户需要量化组合风险时，使用同口径复权后的收益率计算相关性，不使用价格水平；核验日期对齐、停牌、除权、缺失值和样本数。注明窗口和样本时间；不靠填充停牌价格制造零波动。比较不同窗口或下跌期的变化，但不要因某窗口相关性低就判定未来可分散。

历史相关性只能补充已有共同经营驱动及联合压力分析，不能替代它。没有足够价格序列时明确未计算，不编造相关系数。

每次用外部数据能力时说明实际状态：本次成功取数并核验、可用但尚未取数、未配置或调用失败。搜索结果不是已接通行情API。AKShare/yfinance/Wind等仅作为候选来源；接入前另查环境、接口、访问条件与证券覆盖，不自动改代理、不安装整个框架，不把外部依赖列成已经拥有的能力。

## 6. 本地计算工具

`scripts/verify_research.py` 是本次独立编写的标准库工具，无网络访问和券商操作；输出仅核对给定时点或数字，不核实原始公告真实性。Windows可用 `python -X utf8` 调用。

```text
python scripts/verify_research.py time-check --as-of 2026-09-26T15:00:00+08:00 --published-at 2026-09-25T18:00:00+08:00 --available-at 2026-09-25T18:00:00+08:00 --retrieved-at 2026-09-26T16:00:00+08:00
python scripts/verify_research.py market-cap --price 10 --shares 100000000 --reported 1000000000 --tolerance 0.005
python scripts/verify_research.py valuation-cap --value 10 --margin 0.2
python scripts/verify_research.py dividend-cover --fcf 100 --dividend 60
```

参数说明：金额必须先统一币种和单位；market-cap仅支持同一股份类别与价格口径，tolerance为允许的相对误差，例如0.005代表0.5%，不是用户投资参数。dividend-cover只作适用行业、指定同口径现金流的算术演示。所有数字示例均为虚构。

状态 `CHECK_PASS` 仅表示该检查通过；`REVIEW_REQUIRED` 表示数据时点/算术冲突；`NOT_MEANINGFUL` 表示常规覆盖倍数不适用；`INVALID_INPUT` 表示参数不合格。任何状态都不等于股票可以买。
