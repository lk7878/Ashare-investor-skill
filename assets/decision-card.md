# 投资决策卡

用于单个候选或持仓的一页结论；保留与本次问题有关的字段。未核实处写“待核实”，不要编造完整度。详细推导可附后，用户要求存档时另存带日期版本。

## 结论与范围

- 日期、证券代码、市场、价格时点：
- 当前决定及关键原因：
- 能力圈与主要缺口：区分技术/行业熟悉与经营、财务、估值理解；列最影响判断的待验证环节。
- 研究优先级与拟定角色：核心仓/其他价值配置/进攻探索/现金；列依据、待兑现条件和角色失效条件。熟悉领域、低估和仓位角色分别判断，不因标签直接生成交易。
- 排雷 / 理解企业 / 估值有效 / 组合预算：分别填通过、未通过或待核实。
- 流动性及异常交易执行检查：状态、关键证据及日期、替代解释、未知、对新增/持有/减仓的影响、暂停解除条件与复核日期；不得填写无依据的主力意图或操纵概率。
